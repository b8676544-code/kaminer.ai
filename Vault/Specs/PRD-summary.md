# סיכום אפיון (PRD 1.1, מאושר 18.11.2026)

המקור המלא: `docs/PRD.md`

- **משתמשים:** בעלת העסק היא המשתמשת היחידה שמתחברת. פרילנסרים הם רשומות (שיוך משימות ועלות), והתחברות שלהם בשלב ב'.
- **משימות:** ארבע קטגוריות (שיווק, עסקיות, לקוחות, אישיות). סטטוסים: לביצוע, בתהליך, ממתין ללקוח, הושלם. תתי־משימות, הערות, הערכת זמן.
- **אישיות:** קטגוריה בלי לקוח ובלי פרילנסר, פרטית, ולא נכנסת לדוחות העסק.
- **קטלוג:** תבניות למשימות חוזרות, לצד משימות ייחודיות.
- **שעון:** שעון רץ אחד, הזנה ידנית, `is_billable`.
- **יומן:** סנכרון דו־כיווני ל-Google Calendar (polling עם sync token).
- **ריצה:** מקומית, Supabase CLI על Docker ו-Next.js. בהמשך מעבר לענן.
