## זרימה טיפוסית
דף (RSC) ← `queries.ts` של התחום ← לקוח Supabase של השרת ← Postgres עם RLS.
טופס ← server action ב-`actions.ts` ← ולידציה ב-`schemas.ts` (zod) ← כתיבה ← `revalidatePath`.
